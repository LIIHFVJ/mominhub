
# إضافة الزيارات إلى قاعدة البيانات

## ملاحظة هامة

هذا الملف مخصص لإضافة بيانات الزيارات فقط إلى جدول `adhkar` الموجود في قاعدة البيانات دون التأثير على بيانات الأذكار والأدعية الموجودة.

## طريقة الإضافة

لإضافة الزيارات إلى قاعدة بيانات Supabase:

1. تسجيل الدخول إلى حساب Supabase الخاص بك
2. اختيار المشروع المناسب
3. الذهاب إلى قسم "SQL Editor" من القائمة الجانبية
4. نسخ محتوى ملف `add_ziyarat_only.sql` ولصقه في المحرر
5. الضغط على زر "Run" لتنفيذ الاستعلام

## التأكد من عدم وجود تكرار

الاستعلام يتضمن شرط `WHERE NOT EXISTS` للتأكد من عدم إضافة الزيارات المكررة. سيتم إضافة الزيارات فقط إذا لم تكن موجودة مسبقاً بنفس العنوان ونفس النوع (ziyarat).

## التحقق من البيانات

بعد تنفيذ الاستعلام، يمكنك التحقق من إضافة الزيارات بنجاح من خلال تنفيذ الاستعلام التالي:

```sql
SELECT * FROM adhkar WHERE type = 'ziyarat';
```

## استخدام واجهة برمجة التطبيقات (API)

يمكنك استخدام الدوال الموجودة في ملف `src/lib/ziyarat.ts` للتعامل مع بيانات الزيارات في تطبيقك.

## ملاحظات هامة

- هذا الملف يحافظ على جميع بيانات الأذكار والأدعية الموجودة في قاعدة البيانات
- يتم إنشاء فهارس لتحسين أداء الاستعلامات على الزيارات
- في حالة عدم وجود جدول adhkar، سيتم إنشاؤه تلقائياً
